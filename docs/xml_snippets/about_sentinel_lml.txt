  <title xinfo:text="187990">About Sentinel for NH₃</title>
  <para xinfo:text="188014">Sentinel® is an ISOBUS-compatible control and monitoring platform for NH₃ application systems. It provides:</para>
  <itemizedlist>
    <listitem>
      <para xinfo:text="188015">Rate Control: Sentinel Rate Control serves as the primary rate controller for the implement. The ECU monitors machine speed and system performance data and adjusts output to maintain the target application rate.</para>
    </listitem>
    <listitem>
      <para xinfo:text="188016">Row Monitoring: Sentinel Row Monitoring tracks application performance at each row to identify flow variations, restrictions, and blockages. The system utilizes solid-state electromagnetic flow measurement technology to capture flow data without moving parts.</para>
    </listitem>
  </itemizedlist>

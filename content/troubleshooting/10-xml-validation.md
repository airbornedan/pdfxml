# XML validation

If you're editing a topic in the XML view and it won't validate, there are several steps you can take.

1. Select all, copy, then open Copilot.
2. At the prompt, type "This XML won't validate" and paste.
3. Copilot will tell you what the problem is (98% likely)
4. In the prompt, type "Return the complete XML, with the correction in place."
5. Copy the response.
6. In the XML window, Select all (if your selection didn't "stick" and paste.
7. Select Update and it should go.

If you still can't get it to validate:

1. Open a text file and paste in your content.
2. Save that file.
3. In the Paligo XML view, select Cancel
4. Talk to Brad or Dan

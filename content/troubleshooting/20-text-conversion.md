# Text conversion

Some PDF pages contain images of text rather than selectable text. If you
can clearly see/read the text but it won't convert, that is likely the
case.

## How to tell

1. You draw a selection over text you can clearly read on screen.
2. Text / List / Table returns "Nothing could be converted from that
   selection."
3. Open the same page in the original PDF and try to select the text
   with your cursor. If it won't highlight, the page is an image.

## What to do

Use Windows' built-in OCR (Snipping Tool) to lift the text off the page,
one paragraph at a time.

1. Open the PDF in a separate window.
2. Open the Snipping Tool.
3. Select a region.
4. Choose **Text actions -> Copy text**.
5. Open Paligo to the correct topic and create a paragraph.
6. Paste the copied text into Paligo.

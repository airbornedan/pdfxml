# Convert HTML

## Turn a plain HTML/AI-chat paste into Paligo markup

Use this for content that isn't in Paligo's dialect at all -- copied
straight off a web page or out of an AI chat, no `<section>`, still in
its own HTML tags (`<h1>`, `<p>`, `<table>`, `<ul>`).

1. Select the **Convert HTML** card.
2. Paste the HTML and select **Convert**.
3. Wrapper tags are stripped and any lists or tables are converted to Paligo's markup; select **Copy all** to copy the result.
4. Headings and paragraphs are left as HTML -- wrap the result in a `<section>` with a `<title>` and `<para>`s by hand in Paligo's source view. Use **Fix XML** afterward if anything still doesn't check out.

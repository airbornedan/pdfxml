# Fix XML

## Check and fix a topic pasted from Paligo's source view

Use this when a topic already in Paligo won't validate, or came back
from an AI edit with foreign tags mixed in (HTML bold/italic, HTML
lists, CALS tables).

1. In Paligo, select the source view icon (`</>`) and copy the topic's XML (select all, copy).
2. Select the **Fix XML** card.
3. Paste the XML and select **Check**.
4. Foreign tags are translated automatically; anything else wrong is listed below with a line number.
5. Where a fix is offered, open **Suggest a fix** and select it. Otherwise, click directly into the code to edit it, then select **Check again**.
6. Once nothing is left to fix, select **Copy all** and paste the result back into Paligo's source view.

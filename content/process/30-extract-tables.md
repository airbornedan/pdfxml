# Extract tables

## For tables

1. In Paligo, select the source view icon (`</>`).
2. Place your cursor after the closing title tag `</title>` and before the closing section tag `</section>`. You can delete the `<para>placeholder</para>` text.
3. Switch to the PDFXML tool.
4. Select the **Extract** card.
5. Upload the PDF, or continue with the one already loaded.
6. Enter the **Page number** and select **Show page**.
7. Draw a region around the table.
8. Select **Table**. A header row is added automatically when the tool can tell the table has one. The tool extracts selectable PDF text; it does not run OCR.
9. Verify the table text and cell boundaries, then select **Copy all** to copy the LML table markup. If no table text or structure is detected, use your approved online OCR or table-extraction workflow and verify its output externally.
10. Switch back to your open topic in Paligo.
11. Paste the XML into the Paligo topic.
12. Select **Update**.

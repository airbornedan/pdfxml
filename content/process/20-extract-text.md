# Extract text

## For text (paragraphs)

1. In Paligo, select the source view icon (`</>`).
2. Place your cursor after the closing title tag `</title>` and before the closing section tag `</section>`. You can delete the `<para>placeholder</para>` text.  
   If your topic has content already, place the cursor right in front of the last `</section>` tag.
3. Switch to the PDFXML tool.
4. Select the **Extract** card.
5. Upload the PDF, or continue with the one already loaded.
6. Enter the **Page number** and select **Show page**.
7. Draw a region around the paragraph.
8. Select **Text**.
9. Preview the text to make sure it's correct.
10. Select **Copy all** to copy the XML.
11. Switch back to your open topic in Paligo.
12. Paste the XML into the Paligo topic, immediately before the closing `</section>` tag.
13. Click **Update**.
14. View the results to verify.
15. Click **Save** to save the Paligo topic.

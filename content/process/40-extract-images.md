# Extract images

## Extract an image

Extract an image, save it to disk, then upload it to Paligo. This step requires Paligo to be open in the WYSIWYG editor, not the XML view.

### In the PDFXML tool

1. Select the **Extract** card.
2. Upload the PDF, or continue with the one already loaded.
3. Enter the **Page number** and select **Show page**. The preview renders at high resolution so the crop comes out clean.
4. Draw a region around the image.
5. Select **Image**. The rendered region opens in a dialog.
6. Type the file name in the field -- use the correct format, `<product>_<image_type>descriptive_name/partno.`, e.g. `sentinel_ill_ecubracket_400-5320Y1` -- then select **Save PNG**. Select **Watermark** first if the image needs one.

### In Paligo

1. Switch to your Paligo topic.
2. Select **Insert** -> **Image** -> **Image**.
3. Open the correct folder in the Media browser.
4. Select **Add files**.
5. Select the downloaded image.
6. Select **Upload**.
7. The image will be placed in the topic.
